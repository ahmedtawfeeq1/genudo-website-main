# Architecture

## Goals

1. **Identical UI.** The site must render exactly as approved. → Original CSS is
   reused verbatim; page markup and animations are preserved.
2. **Standard, teachable Next.js.** App Router, TypeScript, file-based routing,
   `next-intl`. Nothing exotic.
3. **Reusable components + organized pages.** Shared chrome is real React;
   page bodies migrate to components incrementally.
4. **Multilingual from the start.** English + Arabic, locale-prefixed URLs, RTL,
   Arabic web font — baked into routing and the layout.

## The two layers

### Layer 1 — React chrome + i18n (target state, done)

- `src/components/SiteNav.tsx` / `SiteFooter.tsx` — the mega-menu nav and the
  footer, ported from the original `site-chrome.js` into real components. All
  labels come from `next-intl` messages; internal links use the locale-aware
  `Link` from `src/i18n/navigation.ts`.
- `src/components/LocaleSwitcher.tsx` — EN ⇄ AR on the current route.
- `src/components/GenuRobot.tsx` — React wrapper for the animated mascot builder.
- `src/app/[locale]/layout.tsx` — sets `<html lang dir>`, loads the Tajawal
  Arabic font, imports all global CSS in the original order, provides
  `NextIntlClientProvider`, and renders `<SiteNav/> {children} <SiteFooter/>`.

### Layer 2 — page-body islands (bootstrap, done for all 38 routes)

Each route renders its original page body and mounts its original scripts:

```tsx
// src/app/[locale]/pipelines/page.tsx
import html from '@/legacy-html/pipelines';         // server-rendered as-is
import LegacyScripts from '@/components/LegacyScripts';

export default async function Page({ params }) {
  const { locale } = await params;
  setRequestLocale(locale);
  return (
    <>
      <div className="legacy-page" dangerouslySetInnerHTML={{ __html: html }} />
      <LegacyScripts scripts={['/js/genudo-site.js', ...]} />
    </>
  );
}
```

- `src/legacy-html/<route>.ts` — the page's `<body>` inner HTML (plus any
  page-scoped `<style>`), extracted from the original file. Asset paths were
  rewritten to absolute (`/genu`, `/assets`, `/logos`, `/channels`, `/shots`) and
  internal `*.html` links to clean routes (`/pipelines`, `/blog/<slug>`, …).
- `LegacyScripts` appends the page's behavior files **after** the markup is in
  the DOM, so scripts that read the DOM on load work exactly as before.
- `BodyNav` sets `<body data-nav="…">` for pages whose CSS is scoped to it (e.g.
  who-is-genu's dark-glass header).

The homepage and who-is-genu `page.tsx` are hand-authored (nicely commented) as
the canonical examples; the other 36 were generated by the same rules.

## Routing & i18n

- `src/i18n/routing.ts` — locales `['en','ar']`, default `en`, `localePrefix: 'always'`.
- `src/middleware.ts` — negotiates locale, redirects `/` → `/en`, and skips
  `/public` assets and Next internals.
- `src/i18n/request.ts` — loads `messages/<locale>.json` per request.
- `src/i18n/navigation.ts` — locale-aware `Link`, `useRouter`, `usePathname`.
- `src/app/[locale]/` — every page lives under the locale segment, so both
  `/en/pricing` and `/ar/pricing` exist and are statically generated.

## Styling

The original stylesheets live in `src/styles/` and are imported **once** in the
root layout, in the original cascade order:

```
genudo-site → site2 → genu-robot → concept → home → hero → features → pages → resources → chrome → rtl
```

- `chrome.css` — nav/footer rules that were previously injected by
  `site-chrome.js` (ported; the featured "Who is GENU?" pill now targets the
  class `.nav-featured`).
- `rtl.css` — **loaded last, fully scoped to `[dir="rtl"] / [lang="ar"]`.** It
  applies the Arabic font and mirrors the chrome. English is never affected.

The stylesheets have **no relative `url()` asset dependencies** (only a Google
Fonts `@import`), which is why they import cleanly as global CSS with identical
rendering.

## Assets

Everything the pages load lives under `public/` and is referenced by absolute
path: `/genu/*`, `/logos/*`, `/assets/*`, `/channels/*`, `/shots/*`, and the
behavior scripts under `/js/*`. The mascot builder is `/genu/genu-robot.js`.

## Why islands instead of a full hand-port?

40 pages × pixel-identical output is a large surface. Shipping a running,
identical, localizable site **now** — then componentizing page bodies behind it
— is lower-risk than a big-bang rewrite and lets translation + SEO work start
immediately. See `MIGRATION-GUIDE.md`.
